# Competitive analysis

Warranty trackers (Check My Warranty, WarrantyIO, Android clones) focus on inventory and expiry reminders. Home inventory apps (Stowly, SnapHome, PlanWithHome) focus on rooms and photos. Newer products add receipt OCR.

Keepwise does not copy room-based inventory. The wedge is **confirm-first purchase capture** plus a reliable reminder engine.

| Capability | Typical competitors | Keepwise |
| --- | --- | --- |
| Warranty / maintenance / documents | Strong | Shipped (Item + Coverage) |
| Return window | Uncommon | Coverage kind ReturnWindow |
| Auto capture | Emerging | Inbox + pipeline |
| Email mailbox sync | Emerging | Phase 2 (forwarding first) |
| SMS inbox read | Claimed / risky | Not allowed on Play |
| WhatsApp inbox | Not legitimate | Share/upload only |
| OCR / AI extraction | Emerging | Layered, optional, user-toggled |
| Barcode / recalls | Later | Phase 3–4 |
